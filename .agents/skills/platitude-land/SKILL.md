# Codex からの land

手順・順番・許可・中止条件の正本は [共有 land スキル](../../../.claude/skills/land/SKILL.md)。最初に読み、各段を実施する。このスキルは Codex でのレビュー実施と報告を補う。

## レビューの実施

- 先頭で rebase した後の main と HEAD の SHA を控え、main からの差分全体を [review-points](../../../.claude/skills/review-points/SKILL.md) の全観点で確認する。観点と対象範囲はその正本に従い、依頼と途中の訂正はこの会話で照合する。
- スキルを読むこと、差分の統計、空白検査、テストファイルだけの確認、過去の gate PASS はレビューの代わりにならない。変更した実装とその周辺を読み、指摘の有無を根拠から判断する。
- 同じ会話で読んだ実装や確認結果は、対象の木と前提が変わっていないことを確かめて再利用できる。その場合も差分全体について未確認の観点・範囲を埋める。main が変わった場合は統合後の影響を確認する。
- サブエージェントはユーザーが明示的に許可した時だけ使う。許可が無い時は自分で全観点を確認する。
- 指摘への修正後は、その変更と影響範囲を再レビューする。未確認事項が結論に必要ならレビュー未完了として反映を止め、共有手順の中止条件に従う。

## 反映前の報告

レビュー後、land コマンドを実行する前に次を短く報告する。作業予定ではなく、実施済みの結果を書く。

- レビューした main / HEAD の SHA と対象範囲。
- 重要な確認内容、その根拠となる実装・テスト・文書、指摘と対応。指摘が無い場合も確認内容を示す。
- 未確認事項と検証結果。レビュー結果と gate の結果を分ける。

その後の修正・rebase で木や比較元が変わったら、影響範囲のレビューと報告を更新する。コミット再編だけなら、共有手順で tree の一致を確認して結果を引き継ぐ。

## Codex のフックとの境界

`.codex/hooks.json` は活動記録用で、Claude の許可通知・反映の列への登録・レビュー誘導を実行しない。許可と列の扱いは共有手順に従い、フックとの差を理由にレビューを省かない。このスキルは反映の許可を与えない。

land コマンドの rebase・gate・fast-forward はレビューを実施しない。反映後の報告には、共有手順の項目に加え、反映前に示したレビューの結論を短く添える。
