# Which census lines each gate owes, and on which side — read by `cargo xtask gate`
# and checked against the census by `cargo xtask verbs` (every gate's always-step).
# The reasons are in crates/xtask/src/gate/tiers.rs and internal-docs/反映前テストの機械化.md.
#
# A census line this table does not name: the host before a merge, both sides in the full
# gate (`gate --all`). One row per line it does name, tab-separated:
#
#   <tier>  <census line>  <leans on>  <why>
#
#   linux  also on the container before a merge — judged on a size, a cut or a fold the
#          fonts decide. <leans on> is -.
#   full   the full gate only, both sides. <leans on> is the line(s) run before a merge,
#          ` ; `-separated, that already walk its path — they have to stay so. <why> starts
#          with what tells it from them: git (an answer git gives on the same path), picture
#          (judged by its picture, which no gate reads), held (a cheaper test holds the
#          claim), perf (the perf tool walks it), other. Only held and perf lean on -: the
#          test named in <why>, or the perf tool's own runs, is the witness.
#   twin   no gate: <leans on> is the census line that runs the same path and judges as much.
#          The census does not record a twin, so its line stays out.
