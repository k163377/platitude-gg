## ここまでに言えること

1. 詳細のメタデータ表示だけと、diffを開いた状態には大きな差がある。旧来の「選択あり」は両者を混ぜていた。

5. 自動fetch、表示順序、対象refs、選択対象の条件が旧測定と異なる。旧406–418MiBとの差は条件差の分を含む。
6. 次の比較ではディスプレイ名・報告Hz・DPI・ウィンドウ位置と寸法を保存し、同じ画面とHzに固定する。途中で画面条件が変わったrunは比較から外す。報告Hzと物理走査完了は別である。

## 再実行例

専用worktreeで実ウィンドウの計測が許可された場合に実行する。出力ディレクトリは毎回新しい名前にする。

```text
cargo xtask perf --repo C:/Users/wrongwrong/IdeaProjects/kotlin --selection first --no-diff --no-scroll --runs 3 --breakdown --settle-ms 1000 --output target/perf/details-new
cargo xtask perf --repo C:/Users/wrongwrong/IdeaProjects/kotlin --selection first --runs 3 --breakdown --settle-ms 1000 --output target/perf/scroll-new
cargo xtask perf --repo C:/Users/wrongwrong/IdeaProjects/kotlin --no-select --runs 3 --breakdown --settle-ms 1000 --output target/perf/unselected-scroll-new
```

同一対象に固定する再測定は `--select-oid` と `--file` を指定する。
指定OIDが読み込み範囲に無い、指定ファイルが無い、表示グラフが動かなかった、メモリが採れなかった場合は失敗扱いとなる。
