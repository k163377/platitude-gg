## 区分の読み方

| token | 値 | いつ使うか |
|---|---|---|
| `warning` | `#D97706` | **自分の外へ波及する** / **進行中で対処が要る** / **答えを待っている** / **戻せる破棄**(破棄記録が持つ) |
| `danger` | `#EF4444` | **今止まっている・失敗した** / **戻せない形で手元の成果を捨てる**(進行中の操作の途中の作業・記録が残らない discard・リポジトリの外の物) |

色を持つのは**枠・印・語**。回数押しの白・黄・赤と、押せない時の暗く落とした段の決まりはデザイン規約 §回数押しの色。

## 決まったこと(ユーザー決定)

文と理由の正本はデザイン規約 §回数押しの色。

1. **破棄記録で戻せる破棄は `warning`**(#1・#3・#4・#6〜#9)。**回数押しかクリックかは色の規則と別に決まる**
   ([P3-確認事項.md](P3-確認事項.md) §破棄記録と復元「回数押しは今のまま」)。トークンは足さない
2. **記録が残らない discard は `danger`** —— 最初のコミットの前と、Git LFS が動かない LFS のパスの時だけ(下の「記録が残らない discard」の表)
3. **白の削除は語が色を着ない** —— 印と塗りだけが `warning`、回数押しは 2 回(#2・#43・#44・#51・#52)。`Discard hunk` は
   写しが無い時だけ 2. の `danger`(3 回)
4. **押せない回数押しも印は色相を保つ** —— 語とチップは灰、印はその色の暗く落とした段(#45・#46)
