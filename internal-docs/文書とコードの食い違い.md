# 文書とコードの食い違い(棚卸し)

1 部品だけの決定を文書からその部品のコメントへ移した時に、**元の文書の時点で既にコードと食い違っていた記述**の一覧。
移す時に直したのは「確実に誤り」と言い切れる物と、main で別のセッションが決着させた訂正だけで、ここに並ぶ物は
**直していない**(別のセッションでまとめて決める)。決めたら該当の行を消し、空になったらこの文書ごと消す。

分け方:
- **A 食い違いが残っている** — 文書・コメントの記述とコードが今も食い違う。どちらを正にするかの判断が要る
- **B 確かめずに移した** — 文書の記述をそのままコメントへ移し、コードとは突き合わせていない
- **C 移す時にコードへ合わせた** — 文書の側を古いとみなして落とした / コードどおりに書いた。文書が意図だった場合に備えて確かめる
- **D 以前からの古い引用** — 今回の移動より前から、在らない見出し・語句・節を指していた参照
