# 依存とライセンス(追加・変更の基準)

[CLAUDE.md](../CLAUDE.md) 絶対制約「依存と意匠素材の追加・変更にはライセンス確認と人の許可が必須」の中身。**この基準の変更には人間の明示承認が要る。**

**アプリ本体は MIT。同梱・再配布するものは全て著作権上クリアであること** — crate だけでなく、フォント・アイコン・テーマ等の意匠素材も対象。

## crate

- **明示的に禁止**(`deny.toml` の `[bans]` が機械で守る): **git 実装**(git 操作はシステム git のサブプロセス実行のみ)/ **ネットワーク通信**(通信は git コマンド経由のみ。TLS・ssh の実装も同じ側)。非通信の証明の全体像は [実装計画.md](実装計画.md) §11
- **それ以外の追加・バージョン変更も、ライセンス確認と人の許可が必須**
- **許可するライセンスの集合は `deny.toml` の `[licenses] allow` が正本**(Unicode-3.0 を含む)。集合の編集はこの制約の編集なので人の承認が要る。**GPL 系は禁止**
- **OR の枝に許可外が居ても、許可枝を選べれば違反ではない**(qtbridge 一族の `LicenseRef-Qt-Commercial OR LGPL-3.0-only` は LGPL 側、`MIT OR Apache-2.0 OR LGPL-2.1-or-later` は MIT 側を採る)。**AND は全ての枝が集合に要る**(`(MIT OR Apache-2.0) AND Unicode-3.0` — Unicode-3.0 が集合に在るのはこのため)
- **LGPL-3.0-only は Qt 本体と qtbridge 一族だけの承認済み例外**(`deny.toml` の `[licenses] exceptions`)。条件は動的リンク — 静的リンクは再リンク可能なオブジェクトの提供義務が付くので、別途人の判断([P5-確認事項.md](P5-確認事項.md) §14)
- 検査は `cargo xtask deny`(= `cargo deny check bans sources licenses`。gate が `deny.toml` とマニフェストの変更で回す。`advisories` は RustSec DB を取りに行くので CI だけ)

## 意匠素材(フォント・アイコン・テーマ)

- **許可集合がコード依存と違う**(OFL 等は `deny.toml` の集合に無く、cargo-deny も見ない)ので、**素材は 1 つずつ人の承認**
- 同梱時の帰属表示(LICENSE / NOTICE / 改変告知)の要否はライセンスごとに違う — 配布物の同梱一覧と表示対象は [P5-確認事項.md](P5-確認事項.md) §3 / §15
- **アイコンは全部自前描画**(`NavIcon.qml` の Canvas)で、外部アイコンセットのファイル・パスデータは 1 つも入っていない。**1 つでも取り込めば素材の追加**なので上の 2 行に掛かる —— octicons(MIT)のように許諾のあるものでも、取り込んだ時点で同梱と帰属表示の対象になる

## 追加する時の順

1. SPDX 式を読む(crates.io / `cargo metadata`)。OR ならどの枝を採るかを決め、AND なら全枝を見る
2. 集合の外なら、集合を広げる提案より先に代替を探す(広げるのはこの基準の変更 = 人の承認)
3. 人の許可を得てから Cargo.toml に足し、`cargo xtask deny` を通す(gate も回す)
