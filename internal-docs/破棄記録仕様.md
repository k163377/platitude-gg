# 破棄記録仕様(失った物の一覧と復元)

破壊的な操作が失わせた物を**リポジトリで 1 本の一覧**に出し、そこから**復元**する機能の、製品としての方針。仕様(対象と出さない物・記録の形・一覧の読み方・復元の形・実測で確かめた git の挙動)は実装のコメントが正本 —— 入口は `crates/platitude-core/src/discards/mod.rs`(各モジュールと画面の部品への案内もそこ)。

- **復元は追加の操作** —— 失った物に名前を付けて立て直すか、失った中身を当て直す。既存の ref は動かさない
- **Undo / Redo は持たない**(ユーザー決定。git の操作を Ctrl+Z で戻す機能は作らない)—— 復元の後の統合(枝を
  戻す・cherry-pick する・送り直す)は、利用者が普通の操作で行う
- 意匠(一覧の置き場と見せ方・帯・グラフの仮表示・語)の決定は表示の部品のコメント(`RecoverToggle` /
  `RecoverPane` / `RecoverBand` / `RecoverHoverCard` / `RecoverEntries` / `RecoverMark`、仮表示は `GraphLaneCell` /
  `GraphRowDelegate`)、残りは [P3-確認事項.md](P3-確認事項.md) §破棄記録と復元
- **大きさの上限は持たない**。掃除(大きい物・n 日より前の物を指定して消す)は P5 で足す(未着手。今の保持は
  `crates/platitude-core/src/discards/record.rs` の冒頭)
