# 要望と実装の乖離 — 検討事項

[要望.md](要望.md) と実装・確定意匠を突き合わせた結果、**人間の判断が要る乖離**を積む場所。
解消したらここから消す(経緯は git 履歴が持つ)。照合の実施日: 2026-08-05。

## 要判断

### 1. タグのリモート状態を、雲バッジでどこまで表し分けるか

「リモートにも在るタグに雲」は実装済み(バッジの意匠と `PG_FAKE_REMOTE_TAGS`
プレビューまで)。残りは `ls-remote --tags` を突き合わせた時に出てくる状態で、
それぞれ表し方が決まっていない:

| 状態 | 今どうなるか |
|---|---|
| リモートにしか無いタグ | ローカル ref を列挙しているだけなので、そもそも画面に出ない |
| ローカルにしか無いタグ | バッジ無し(= 決定どおり) |
| 同名でリモートとローカルが別のコミットを指す | 雲が出る(在る / 無いしか見ていない) |

P4 のデータ接続(`ls-remote --tags`)より前に決める。

## 軽微(急がないが記録)

### 2. ダイアログ見出しの段が二群に割れている

Stash / Settings / Identity は `fontXl`、Confirm / DirtySwitch の見出しは `fontLg`。
デザイン規約の表はどちらも合法(`fontXl` = ダイアログタイトル(稀)、`fontLg` =
ダイアログ内の強調)で、表だけでは決まらない。統一するか、規約に基準を一行
足すかは要判断。

### 3. グラフのチップ貼り替え(`LabelsChanged`)に世代ガードが無い

他の graph メッセージは世代で守られているが、`Labels` だけ素通しのため、
リセットと入れ違うと**一瞬**チップが別の行に付き得る(次の refs 読みで自己修復。
決定的な再現は未取得)。要望「リポジトリの全状態表示」の正確性に関わるので、
P5 までに世代タグを足すか判断する。
