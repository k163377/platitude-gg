# 要望と実装の乖離 — 検討事項

[要望.md](要望.md) と実装・確定意匠を突き合わせた結果、**人間の判断が要る乖離**を積む場所。
解消したらここから消す(経緯は git 履歴が持つ)。照合の実施日: 2026-08-05。

## 要判断

### 1. タグの「ローカルのみ」区別が、要望・確定意匠・実装計画で三すくみ

三つの記録が互いに矛盾している:

| 出典 | 内容 |
|---|---|
| [要望.md](要望.md) 必須要望 | 「ローカル / リモートタグ表示(**ローカルのみのものは区別したい**)」 |
| CLAUDE.md 確定意匠 | 「**タグの「ローカルのみ」区別は無表示が確定意匠**(バッジを足さない)」 |
| [実装計画.md](実装計画.md) §7(P4) | 「ローカルのみタグ区別バッジへのデータ接続(fetch サイクルで `ls-remote --tags` と突合)」 |

現実装はタグ行にバッジ類を一切描かない(`NavItemDelegate` の状態アイコンは
branch / remote / worktree のみ)。つまり現状のままだと**必須要望の一項目が
最後まで満たされず**、P4 のデータ接続タスクは接続先のバッジが存在しない。

選択肢:

- (a) 確定意匠を優先し、要望から当該項目を撤回する(要望.md と実装計画 §7 を修正)
- (b) ブランチと同じ「雲」アイコンをリモートに在るタグへ出す(= 無表示なのは
  ローカルのみタグ、という区別で要望を満たす)。確定意匠の「バッジを足さない」を
  「ブランチと同じバッジ体系をタグにも使う」へ改める
- (c) 別の表現(色・チップの塗り等)。デザイン規約へのトークン追加は人間承認が必要

## 軽微(急がないが記録)

### 2. ダイアログ見出しの段が二群に割れている

Stash / Settings / Identity は `fontXl`、Confirm / DirtySwitch の見出しは `fontLg`。
デザイン規約の表はどちらも合法(`fontXl` = ダイアログタイトル(稀)、`fontLg` =
ダイアログ内の強調)で、表だけでは決まらない。統一するか、規約に基準を一行
足すかは要判断。

### 3. グラフのチップ貼り替え(`LabelsChanged`)に世代ガードが無い

他の graph メッセージは世代で守られているが、`Labels` だけ素通しのため、
リセットと入れ違うと**一瞬**チップが別の行に付き得る(次の refs 読みで自己修復。
決定的な再現は未取得)。要望「リポジトリの全状態表示」の正確性に関わるので、
P5 までに世代タグを足すか判断する。
